# 📚 Prompt Templates Library

Here is a collection of ready-to-use prompts for different scenarios. Just copy, paste, and customize the details in the brackets `[ ]`.

## 🧑‍💻 For Software Engineers
* **Code Review:** "Review the following code for security vulnerabilities and suggest optimizations: \n\n `[insert code]`"
* **Bug Fixing:** "I am getting a `[insert error message]` in my `[language]` code. What are the common causes and how can I fix it?"
* **Explaining Code:** "Explain this code block step-by-step as if I am a beginner: \n\n `[insert code]`"

## 🎓 For Students
* **Summarize Text:** "Summarize the following text into 5 bullet points highlighting the key concepts: \n\n `[insert text]`"
* **Study Plan:** "Create a 7-day study plan to learn `[topic/subject]` for an upcoming exam. Include daily goals and resources."

## 💼 For Entrepreneurs & Marketers
* **Social Media:** "Write an engaging LinkedIn post about `[topic]`. Include relevant hashtags and a call-to-action."
* **Email Drafting:** "Write a polite and professional email to `[client name]` following up on the proposal sent on `[date]`."
