# ❓ Frequently Asked Questions (FAQ)

Here are some of the most common questions beginners have about Microsoft Copilot.

**1. What is the difference between Microsoft Copilot and ChatGPT?**
While both use OpenAI's GPT models, Microsoft Copilot is deeply integrated into the Microsoft ecosystem (like Edge, Windows, and Microsoft 365). It also has real-time web access (grounding) via Bing search by default, whereas ChatGPT provides a more generalized chat experience.

**2. Is my data safe when using Copilot?**
Yes. If you are using Copilot with commercial data protection (usually with a school or work account), Microsoft does not save your prompts, nor do they use your data to train their models. Always ensure you are signed in to see the "Protected" badge.

**3. Do I need to pay to use Microsoft Copilot?**
The standard Microsoft Copilot on the web (copilot.microsoft.com) is completely free to use. However, there is a premium version called **Copilot Pro** for individuals, and **Copilot for Microsoft 365** for enterprises, which offer faster performance and direct integration into Word, Excel, and PowerPoint.

**4. Can Copilot generate images?**
Yes! Microsoft Copilot uses DALL-E 3 to generate high-quality images. Just prompt it by saying "Generate an image of..." or "Create a picture of...".
